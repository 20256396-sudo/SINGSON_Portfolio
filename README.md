# Rainnier Singson — Portfolio Website

Personal portfolio website by **Rainnier Singson**, a student Filipino filmmaker, director, and VFX artist. Built as a single-page application showcasing my demo reel, featured work, and contact information.

---

## Live Sections

| Section | Description |
|---|---|
| **Hero** | Full-screen background video with animated title reveal |
| **Demo Reel** | Preview video that opens a YouTube modal on click |
| **Featured Work** | Filterable project grid (Music Videos, Commercials, VFX, Films) |
| **About** | Bio and profile photo |
| **Contact** | Email link and social media handles |

---

## Project Structure

```
/
├── index.html          # Main HTML — single-page layout
├── styles.css          # All styling (responsive, dark theme)
├── script.js           # Interactivity (nav, modal, tabs, scroll tracking)
├── fastpreview.mp4     # Hero background video (1280×720, ~10s loop)
├── preview.mp4         # Demo reel preview video
└── rainnier.jpg        # Profile photo (About section)
```

---

## Features

- **Sticky navigation** with a sliding highlight indicator and scroll-aware active state
- **Hero background video** with blur and cinematic dark overlay
- **Demo reel modal** — clicking the preview opens a YouTube embed with autoplay
- **Filterable project grid** — tabs for All Work, Music Videos, Commercials, VFX Showcase, and Films
- **Smooth scroll** with nav offset compensation
- **Mobile responsive** — hamburger menu, stacked layouts, adjusted typography
- **Video fallback** — hides iframe and shows a fallback link if the embed fails to load

## Tech Stack

Plain HTML, CSS, and vanilla JavaScript — no frameworks or build tools required.

- **Font stack:** System UI (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, etc.)
- **Color scheme:** Dark (`#0b0b0f` base, `#111115` section alternates)
